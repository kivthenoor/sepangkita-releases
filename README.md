# SepangKita

Flood watch for the Sepang community: river levels, flood gauges, sirens, rainfall, CCTV,
MET warnings, flood news and alerts, in Bahasa Melayu and English. Developed by Akif Fauzi.

## Download for Android

**[⬇ Download SepangKita 1.0.3 (APK)](https://raw.githubusercontent.com/kivthenoor/sepangkita-releases/main/apk/SepangKita-latest.apk)**

Android 8.0 or newer. Open the file on your phone and allow your browser to install apps
when Android asks. Already installed? The app tells you when there's an update, or open
**Settings → Check for updates**.

## Check your download

Every release is built and signed automatically by GitHub Actions with the SepangKita
release key. The SHA-256 of version 1.0.3 is:

```
253d07da1664eef69f5c7799d7b7656d889ee5be9afd88deb13d2adf1b20bc07
```

The app checks this fingerprint itself before installing an update, and Android refuses
any update that isn't signed with the same key.

Older versions are in the [`apk`](apk) folder. `version.json` tells the app which version
is the newest.
